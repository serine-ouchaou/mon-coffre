
## 1. Se connecter à GitHub

1. Ouvrir le site Github

2. Se connecter à son compte GitHub.

3. Cliquer sur le bouton **+** situé en haut à droite.

4. Sélectionner **New repository**.


## 2. Configurer le dépôt

1. Saisir le nom du dépôt dans le champ **Repository name**.

2. Ajouter éventuellement une description du projet.

3. Choisir si le dépôt doit être **Public** ou **Private**.

4. Cocher **Add a README file** si nécessaire.

5. Cliquer sur **Create repository**.

## 3. Vérifier la création

Une fois le dépôt créé, GitHub affiche sa page d'accueil.  
Le dépôt contient alors les fichiers sélectionnés lors de sa création.

## 4. Cloner le dépôt sur son ordinateur

Pour récupérer le dépôt sur son ordinateur, copier son URL depuis GitHub puis utiliser la commande suivante dans un terminal :

git clone httpsXXXXXXXXXXXXXX 

se rendre dans le dossier par : cd dossier

Après avoir ajouté ou modifié des fichiers, utiliser les commandes Git suivantes :

git add .
git commit -m "Votre commentaire"
git push

Le dépôt GitHub est maintenant créé et peut être utilisé pour sauvegarder et partager le projet.
